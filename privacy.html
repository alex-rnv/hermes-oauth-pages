Privacy Policy

Last updated: 2 October 2026

Hermes Personal Assistant ("the application") is a private tool operated by a single individual ("the owner") for the owner's own use. This policy explains how the application handles data.

Who this applies to

The application is used only by its owner, to access the owner's own Google account. It does not have other users and does not access any other person's data.

What data is accessed

With the owner's explicit consent, the application accesses the owner's own Google Workspace data through Google's official APIs. Depending on the permissions granted, this may include Gmail messages, Google Calendar events, Google Drive files, Google Sheets, and Google Docs. The application accesses this data solely to perform tasks the owner requests.

How data is used

Data is used only to carry out the owner's own instructions (for example, reading an email, creating a calendar event, or downloading a file). The application does not sell data, does not share data with third parties, and does not use data for advertising or for training machine-learning models.

How data is stored

The application runs locally on the owner's own computer. OAuth tokens are stored locally on that machine to maintain the connection to Google. Any file contents accessed are processed locally and are not transmitted to any third-party server controlled by the application.

Google API Services User Data Policy

The application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The owner can revoke the application's access at any time at https://myaccount.google.com/permissions.
